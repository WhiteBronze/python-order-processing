# Анализ заказов

## Что сделано

### 1. Класс `OrderAnalyzer` (`src/analyzer.py`)

Класс для пакетной обработки файлов с заказами.

**Методы:**

- `__init__()` — инициализирует объект без загрузки данных. Данные загружаются только при вызове `process_file()`.

- `filter_delivered()` — фильтрует заказы со статусом "доставлен" (значение берётся из `config.py`). Если колонки со статусом нет — записывает ошибку в лог и возвращает `None`.

- `calculate_metric()` — считает три метрики по доставленным заказам:
  - общая выручка (сумма `total_amount`)
  - средний чек (среднее `total_amount`)
  - количество заказов
  
  Перед расчётом преобразует `total_amount` в числовой тип через `pd.to_numeric()`. Если преобразование не удалось — записывает ошибку в лог и возвращает `None`.

- `process_file(file_path)` — загружает файл, приводит названия колонок к нижнему регистру и возвращает результат `calculate_metric()`. Ошибки загрузки логируются.

- `process_all_files(data_dir)` — находит все CSV-файлы в папке, обрабатывает каждый через `process_file()`, собирает результаты и считает количество ошибок. Возвращает список результатов.

- `save_results(results)` — сохраняет итоговую таблицу в `reports/summary_report.csv`.

### 2. Настройки (`config.py`)

Все настройки вынесены в отдельный файл:
- `DATA_DIR` — папка с CSV-файлами
- `REPORTS_DIR` — папка для результатов
- `LOGS_DIR` — папка для логов
- `OUTPUT_FILE` — имя выходного файла
- `STATUS_COLUMN` — название колонки со статусом
- `DELIVERED_STATUS` — статус для фильтрации
- `AMOUNT_COLUMN` — название колонки с суммой

### 3. Точка входа (`run.py`)

- Создаёт объект `OrderAnalyzer()`
- Вызывает `process_all_files()` для обработки всех CSV-файлов в `data/`
- Вызывает `save_results()` для сохранения результата
- Выводит в консоль количество обработанных файлов и количество ошибок

### 4. Логирование

Ошибки пишутся в файл `logs/errors.log` с указанием времени. Используется стандартная библиотека `logging`. Логируются:
- ошибки загрузки файлов
- отсутствие нужных колонок
- ошибки преобразования типов
- ошибки при расчёте метрик

### 5. Устойчивость

- Если один файл повреждён или имеет неверный формат — он пропускается
- Ошибка записывается в лог
- Обработка остальных файлов продолжается

### 6. Зависимости (`requirements.txt`)

- pandas — для работы с данными
