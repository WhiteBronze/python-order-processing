# Анализ заказов

## Что сделано

### 1. Класс `OrderAnalyzer` (`src/analyzer.py`)

Класс для обработки одного файла с заказами.

**Методы:**

- `__init__(file_path)` — загружает CSV-файл, приводит названия колонок к нижнему регистру. Если файл не загрузился — записывает ошибку в лог.

- `filter_delivered()` — фильтрует заказы со статусом "доставлен" (значение берётся из `config.py`). Если колонки со статусом нет — записывает ошибку в лог.

- `calculate_metric()` — считает три метрики по доставленным заказам:
  - общая выручка (сумма `total_amount`)
  - средний чек (среднее `total_amount`)
  - количество заказов
  
  Если колонки с суммой нет — записывает ошибку в лог.

- `_log_error(message)` — внутренний метод для записи ошибок в `logs/errors.log`.

### 2. Настройки (`config.py`)

Все настройки вынесены в отдельный файл:
- `STATUS_COLUMN` — название колонки со статусом
- `DELIVERED_STATUS` — статус для фильтрации
- `AMOUNT_COLUMN` — название колонки с суммой
- `REPORTS_DIR` — папка для результатов
- `LOGS_DIR` — папка для логов
- `OUTPUT_FILE` — имя выходного файла

### 3. Точка входа (`run.py`)

- Находит все CSV-файлы в `data/`
- Для каждого файла создаёт объект `OrderAnalyzer` и считает метрики
- Собирает результаты в список
- Сохраняет итоговую таблицу в `reports/summary_report.csv`
- Ошибки записываются в `logs/errors.log`

### 4. Логирование

Ошибки пишутся в файл `logs/errors.log` с указанием времени. Используется стандартная библиотека `logging`.

### 5. Зависимости (`requirements.txt`)

- pandas — для работы с данными
